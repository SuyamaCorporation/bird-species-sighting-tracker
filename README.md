# Bird Species Field Observation Tracker
バードウォッチングの観察記録（種名・場所・日時・個体数）をログ。ライフリスト管理。

## Features
- Log sightings with species, location, date, count, weather, and behavior notes
- Life list tab showing unique species alphabetically with first-seen date and total individuals
- Chronological sighting log with delete capability
- Stats dashboard: species count, total individuals, most-seen species, and monthly activity heatmap
- Search and filter life list by species or location; all data persisted in localStorage

## Usage
Use the **Add Sighting** tab to log each observation. Switch to **Life List** to browse your species collection or **Stats** for summary analytics. Search the life list by typing in the search box.
